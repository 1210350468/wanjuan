# 1.4.1

## 中文

1.4.1 把番茄书库的选书评分换成了可解释的推荐系统口径，并让写作直接用上你本机已经登录的命令行工具。作品数据、设置和安装位置都不变。

新功能：

- 本机执行器：在「设置 → AI 模型 → 服务商」里选「本机执行器（CLI）」，可以用已安装的 Codex、Gemini CLI、Claude Code 或 agy 当写作模型，不用填 API Key。命令带 `{{prompt}}` 时把正文放在这个位置，不带时从标准输入送入。
- 设置页会自动扫描 PATH 与常见安装目录，跑一次 `--version` 看版本，并检查凭据文件在不在；每行给出「已安装 / 没找到登录凭据 / 登录状态未知」。点「用这个」自动填好显示名称、命令和参数；点「登录」在系统终端里打开官方登录流程，切回应用后自动重新检测。检测只读，不读凭据内容，也不上传任何数据。
- 番茄书库可以点「AI 帮我选」，让模型在当前候选里自己判断挑哪几本，并给出理由。书号必须来自当前候选，读不出结果会明确报错，不会悄悄换书。

改进：

- 书库评分换成推荐系统口径：热度按对数刻度，追读用带先验权重的评分（章数少的书不会靠高分冒头），节奏按字数与目标长度的距离衰减，题材集中度按标签两两重合的平均算。卡片显示综合分与六项分数，配单里写清楚每项怎么算、依据是什么。
- 书库卡片、配单结果和设置页的执行器面板都重拍了示意图，README 的三语说明与实际操作保持一致。
- 书库顶栏的设置入口改成带文字的纸色按钮，侧栏底部的设置行加了纸卡和朱印图标；顶栏其他图标按钮也提高了与深色木条的对比度，不再糊成一片。

修复：

- 知识库单飞导入的两项测试在假计时器下会被轮询推进时间，误判成授权过期；现已改为等待真实的请求信号。
- LanceDB 契约测试在受限运行时里会因递归复制被拦截而结束进程；现已改成逐文件复制。

本页先提供 Windows x64 安装包；macOS 安装包未随本次发布提供。Windows 安装包未做代码签名，系统可能提示未知发布者。

## English

1.4.1 replaces the Fanqie book picker's scoring with an explainable recommendation-style model, and lets your writing use command-line tools already signed in on your machine. Project data, settings, and the install location are unchanged.

New features:

- Local harnesses. Under Settings → AI model → Provider, choose Local harness (CLI) to write with an installed Codex, Gemini CLI, Claude Code, or agy — no API key needed. If the command contains `{{prompt}}`, the text is placed there; otherwise it is sent through standard input.
- Settings automatically scans PATH and common install directories, runs `--version` once, and checks whether a credential file exists; each row shows Installed / No sign-in found / Sign-in state unknown. Use this fills in the display name, command, and arguments. Sign in opens the official login flow in your system terminal, and the app rechecks when you come back. Detection is read-only: it never reads credential contents or uploads anything.
- In Fanqie book library, AI pick lets the model judge which of the current candidates are worth writing and explain why. Book IDs must come from the current candidates, and an unreadable result is reported instead of silently changing books.

Improvements:

- Book scoring now uses an explainable recommendation-style model: logarithmic popularity, a prior-weighted score for reader retention so short books cannot coast on a perfect rating, a distance-based rhythm score around the target chapter length, and average pairwise tag overlap for topic coherence. Cards show the overall score and six subscores, and the fusion dialog explains how each is computed and what it is based on.
- Screenshots for the book cards, fusion results, and the harness panel were retaken, and the README in all three languages now matches the actual workflow.
- The Settings entry in the library top bar is now a labeled paper-colored button, and the sidebar entry is a distinct paper card with a vermilion icon. Other top-bar icon buttons also have better contrast against the dark wood strip.

Fixes:

- Two knowledge-base single-flight tests advanced fake time through polling and mistook that for an expired import authority; they now wait for the real request signal.
- The LanceDB contract test could kill its worker when recursive copying was intercepted in a restricted runtime; it now copies files one by one.

This release provides a Windows x64 installer only; no macOS installer is included. The Windows installer is unsigned, so your system may warn about an unknown publisher.
