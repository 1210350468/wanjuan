# 万卷 Wanjuan v2.0.0

万卷是从 Pagekin 派生的本地优先 AI 长篇小说写作台。这一版完整承接上游的设定、架构、章节蓝图、正文、审稿修稿与定稿流程，并加上三件事。

## 番茄书库

- 男频 19 个、女频 18 个题材榜单，带封面、作者、简介、字数、连载状态与在读人数。
- 关键词搜书（Bing 站内检索定位书号，失败回退榜单书名匹配），也支持直接贴书籍页链接或纯书号。
- 勾选 2 到 5 本，写融合取向，一键新建作品并按参考作品的中位规模写好总章数与每章字数，再让 AI 生成设定与核心大纲。
- 榜单列表的字有防抓取替换，所以只取书号；书名与简介一律回公开书籍详情页读取。章节正文受字体混淆保护，不读取、不还原。

## 写作 Skill 超市

- 按关键字搜 GitHub 仓库，结果带仓库简介、星标与最后更新时间。
- 扫描仓库里的全部 SKILL.md，勾选后逐个检查并安装。
- SKILL.md 引用的 references 文本一并下载；仓库把 references 放在根目录共用时也能找到。
- 依赖脚本、hook、子代理或合并后超过 64 KiB 的 Skill 会被标出原因并拒绝安装。中文目录名与附带文件路径均支持。

## 新手引导与界面

- 首次打开且书架为空时给四步引导；空书架页可随时重看。
- 书房顶部横幅与封面墙，入口图标统一；番茄书库改为封面卡片网格。

## 兼容与数据

- 包名、appId、数据目录与项目格式沿用上游，升级安装不会重开一份书架。
- 产品显示名与安装包文件名改为万卷 / wanjuan。
- GPL-3.0 不变；上游署名与改动说明见 NOTICE.md。

## 已知限制

- 番茄榜单没有可用的公开分页接口，每个分类列出该题材几套榜单合并后的作品，最多 18 本。
- 关键词检索依赖 Bing；网络受限时可用书籍链接直接读。
- 软件不带模型，写作、审稿和 AI 填充需要先在设置里配置服务。
