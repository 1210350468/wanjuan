## 小红书正文

最近把一个开源写作软件改成了自己想要的样子，叫「万卷」。

最实用的三个变化：

📚 **番茄书库**：男频 19 个、女频 18 个题材榜单，封面、简介、字数、连载状态都能看。勾两本以上，按它们的题材与章节节奏融合出一部新书的设定。

🧩 **Skill 超市**：贴一个 GitHub 仓库就能扫出里面全部 SKILL.md，勾选批量装。也能按关键字找仓库，结果带简介、星标与更新时间。带 references 的技能会连参考文本一起下载；依赖脚本的会标出原因拒绝安装。

✍️ **完整写作流程**：设定 → 架构 → 章节蓝图 → 正文 → 审稿修稿 → 定稿，每一步都能人工确认。写作 Skill 可以绑到规划、写稿、审稿、修稿四个阶段。

作品都放在本地文件夹，软件不带模型，接自己的 API Key 或本机 Ollama 就能用。开源 GPL-3.0。

标题：万卷 Wanjuan：给长篇小说写作者做的本地工作台，加了番茄书库与 GitHub Skill 超市

正文结构：
1. 这是什么：Pagekin 的 GPL 派生版，面向长篇与网文。
2. 解决了什么：选题分散、参考素材难结构化、写作规则难复用。
3. 技术实现：Electron + React + TypeScript + SQLite；番茄书库读公开书籍详情页，榜单页只取书号，书名和简介回详情页读（列表文字有防抓取替换）；章节正文有字体混淆，明确不读取。
4. GitHub Skill 超市：GitHub 仓库搜索与 tree API 扫描，SKILL.md 引用的文本一并下载，脚本/hook/子代理检测后拒绝安装。
5. 数据边界：作品本地，模型自配，无账号体系。
6. 许可与上游：GPL-3.0，保留 Pagekin 署名，见 NOTICE.md。

## 演示录屏动线（约 60 秒）

1. 打开书房，展示顶部横幅与封面墙（5 秒）。
2. 点「番茄书库选题」→「分类榜单」，切一次男频/女频、点一个题材，展示封面网格（15 秒）。
3. 勾两本书 → 填融合取向 → 展示融合简报内容（生成部分可剪短）（15 秒）。
4. 设置 → 写作 Skills → Skill 超市 → 按关键字搜仓库 → 看技能 → 勾选安装（15 秒）。
5. 回到书房，展示新手引导的任一步与「本地优先」说明（10 秒）。
